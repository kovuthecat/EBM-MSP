### Profil #0 — VIERGE (buildDefaultCriteria — cas le plus surveillé)

Critères saisis :

  - ASCVD_etablie = false
  - anciennete_diabete_annees = 0
  - autres_FDRCV = 0
  - diabete_complique = false
  - dialyse = false
  - statine_deja_en_place = false
  - intolerance_statine = false

Sortie :
  Famille « (repli à plat) » (exclusive: n/a) :
  - [recommandee] Discuter la statine (décision partagée) — diabète non compliqué à faible risque absolu
      proposé parce que : anciennete_diabete_annees < 10 ; autres_FDRCV == 0 ; diabete_complique == false
  Alertes de nœud :
    - Absence de tout critère de la grille (diabète récent, non compliqué, sans autre facteur de risque cardiovasculaire) : le risque absolu est probablement faible, et l'outil SCORE2-Diabète peut aider à l'objectiver (seuils fixes ESC 2023 : faible < 5 %, modéré 5-<10 %, haut 10-<20 %, très haut ≥ 20 %). Réserve : SCORE2-Diabète n'est validé que 40-69 ans (SCORE2-OP / jugement clinique au-delà) — un profil sans critère de la grille est souvent JEUNE, donc potentiellement hors de la plage de validation de l'outil qu'on lui suggère de calculer. [info]
    - La décision (traiter / discuter) et l'intensité se gradent sur le RISQUE ABSOLU, pas sur une cible LDL chiffrée : aucun ECR ne valide une valeur cible de LDL (LODESTAR : viser une cible ≡ dose fixe ; VA/DoD 2026 : preuve insuffisante pour le treat-to-target), et le bénéfice est indépendant du LDL de base (HPS). [info]

  - [recommandee] Statine (prévention primaire, intensité modérée — haute si risque très élevé)
      proposé parce que : default
  Alertes de nœud :
    - Patient en dialyse : le bénéfice d'une statine n'est pas démontré sur les critères durs dans cette population (4D chez le DT2 hémodialysé : critère principal RR 0,92 NS, avec un signal d'AVC fatal ; AURORA : neutre malgré −43 % de LDL). Chez un patient dialysé SANS statine en cours, l'option de haute intensité (prévention secondaire) n'est plus proposée par cet outil — retrait structurel, pas seulement un rappel. Si une statine est DÉJÀ en place, sa poursuite reste raisonnable et les options ci-dessus s'appliquent normalement. En maladie rénale chronique NON dialysée, la statine reste indiquée. [attention]
    - La décision (traiter / discuter) et l'intensité se gradent sur le RISQUE ABSOLU, pas sur une cible LDL chiffrée : aucun ECR ne valide une valeur cible de LDL (LODESTAR : viser une cible ≡ dose fixe ; VA/DoD 2026 : preuve insuffisante pour le treat-to-target), et le bénéfice est indépendant du LDL de base (HPS). [info]
  Options écartées (sécurité, R4) :
    - Statine de haute intensité — prévention secondaire (maladie athéromateuse établie) :: dialyse == true AND statine_deja_en_place == false
