## T-128 — La bulle de survol et le panneau s'affichent en double

### Objectif

Qu'un clic sur une pastille n'affiche pas deux fois le même texte, superposés.

### Décision clé

Recette du 02/08, vignette N1 :

> « Cliquer une pastille ouvre **deux fois** le même texte : l'info-bulle de survol (fond sombre,
> `pastille-info__bulle`) reste affichée par le focus **par-dessus** le panneau dépliant qui affiche
> le même contenu juste en dessous. Mesuré : bulle de y 477 à 529, panneau à y 504 — ils se
> chevauchent sur 25 px. »

La bulle est révélée sous `@media (hover: hover) and (pointer: fine)` sur `:hover` **et**
`:focus-visible`. Le clic donne le focus **et** ouvre le panneau : les deux se cumulent. Le correctif
est de masquer la bulle quand le panneau correspondant est ouvert — pas de supprimer le
`:focus-visible`, qui est le seul accès clavier à la bulle quand le panneau est fermé.

**Modifier** : `src/features/shared/ui/PastilleInfo.css`, et `PastilleInfo.tsx` seulement si l'état
« panneau ouvert » n'est pas déjà exprimé sur le bouton (attribut `aria-expanded` ou classe).
Mettre à jour `PastilleInfo.test.tsx`.

### Validation

- **N0 auto** : `npm test` → vert · `npm run typecheck` → 0 erreur · `npm run build` → OK.
- **N1 visuel auto** : au clic sur une pastille, **un seul** texte visible ; au survol seul, la bulle
  revient ; au clavier (Tab + Entrée), l'accès reste possible. → `/verif-visuelle`
