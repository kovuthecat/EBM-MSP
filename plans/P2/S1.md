## T-011 — Inventaire structuré des éléments partagés entre nœuds

### Objectif

Extraire, dans une structure comparable, tout ce qui est susceptible d'être partagé/divergent entre
nœuds, pour alimenter l'audit de valeurs (S2) et la red-team données (S3).

### Décision clé

Fan-out d'agents Haiku, **un par catégorie**, chacun balayant les 7 YAML. Sortie = un seul JSON
consolidé. Chaque entrée porte sa **provenance `fichier:ligne`** (traçabilité non négociable).

### Lire / Modifier

- Créer : `docs/decision/validation/inventaire.json`.

### Étapes

1. **Seuils numériques** : toute occurrence de `DFG`, `HbA1c`, `IMC`, `age`, `esperance_vie`… (dans
   `conditions`, `exclusions`, `priorite.quand`, `alertes.quand`, prose `contre_indications`/`effet_attendu`),
   avec `{valeur, opérateur, nœud, clé, justification_citée?, fichier:ligne}`.
2. **Molécules** : chaque molécule (metformine, empa/dapa/canagliflozine, séma/dula/liraglutide,
   tirzépatide, sitagliptine, gliclazide/glimépiride, saxa/linagliptine, rosuvastatine…) avec
   `{orthographe, nœud, dose_ou_palier?, CI_mentionnée?, fichier:ligne}`.
3. **Critères d'entrée** (`criteres_entree`) : `{nom, type, valeurs?, unité_implicite?, derive?, nœuds[]}`
   — regrouper par `nom` pour exposer les **homonymes** (même nom déclaré dans ≥2 nœuds).
4. **Garde-fous** : pour chaque nœud, la liste `exclusions` (DSL) **et** `contre_indications` (prose),
   appariées quand elles portent sur le même objet (pour la parité prose↔DSL en S2).
5. **Couplages inter-nœuds** : champs `derive`, mentions « nœud A », `cible_atteinte`, `terrain_fragile`,
   `HbA1c_cible`… avec `{expression, nœud, référence_vers, fichier:ligne}`.
6. **Catalogue de critères candidat** (double emploi) : à partir de (3), émettre une liste **canonique
   provisoire** `{nom, type, valeurs, nœuds}` — matière première de S2 **et** de la future persistance
   partagée des critères (cf. `index.md` §Suite / `TASKS` T-019).

### Validation

- Auto : le JSON est parseable ; les 7 YAML sont couverts (chaque fichier apparaît ≥1 fois).
- Structurelle : chaque entrée porte une provenance `fichier:ligne` ; les 6 catégories sont présentes.

### Si bloqué

- Valeur ambiguë (ex. seuil dans une phrase libre) : l'extraire **verbatim** dans un champ `brut` + la
  localisation, laisser S2 trancher. Ne jamais STOP pour une ambiguïté d'extraction.
