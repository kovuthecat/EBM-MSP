## T-195 — Rendre la note de source comme troisième registre du panneau

### Objectif

Un item de `posologie_detail` en forme objet affiche son texte au registre habituel, et ses sources en
**note discrète** dessous — jamais en incise dans la phrase.

### Décision clé

**Un id inconnu est ignoré ICI, en silence** — politique déjà écrite dans le composant (~l. 384-387) :
le signaler est le travail d'un invariant de contenu (S3), pas d'un composant de rendu au milieu d'une
consultation. **Ne pas ajouter de message d'erreur, de `console.warn`, ni d'affichage d'id brut.**

Le registre visuel : la note est le **troisième** niveau, sous `--posologie-modalite`. Elle ne doit pas
concurrencer le geste. Réutiliser les tokens existants ; le rendu de référence est la ligne
« D'après : » du panneau `--preuves` (liens `target="_blank" rel="noreferrer"` quand la référence a un
`lien`).

### Lire / Modifier

Modifier : `src/features/decision/components/OptionCard.tsx`, `OptionCard.css`, `OptionCard.test.tsx`.

### Étapes

1. La normalisation de forme (`string` ⇒ texte) **existe déjà**, posée par S1 — ne la duplique pas,
   étends le bloc en place.
2. Résoudre `item.sources` contre la `Map parId` existante, **étendue au second registre**
   (`sources.reco_officielle.references[]`, qui porte un `id` depuis S1). Une entrée sans `id` n'est
   simplement pas résoluble : elle n'entre pas dans la map.
3. Rendre la note sous l'item. Classe dédiée, pas de réemploi de `--posologie-modalite`.
4. Tests : item chaîne (rendu inchangé) · item objet avec sources connues · item objet avec **source
   inconnue** (aucune note, aucune erreur, le texte reste rendu) · item objet sans `sources`.

### Validation

- **N0 auto (bloque le commit)** : `npm run typecheck` · `npm test` · `npm run build` → verts.
- **N1 visuel auto** : aucun contenu n'utilise encore la forme objet — vérifier la **non-régression**
  du panneau sur `insuline` (« Titrer la basale ») et `prescription` (« Envisager l'insuline ») :
  hiérarchie et pastille inchangées, zéro erreur console → `/verif-visuelle`.
- **N2 humain** : le poids visuel de la note ne concurrence pas le geste — à consigner dans
  `VALIDATION.md` **seulement après S5**, quand du contenu réel l'utilisera.

### Si bloqué
