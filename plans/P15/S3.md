## T-197 — Tout id cité en posologie existe dans la bibliographie du nœud

### Objectif

Transposer I8b au nouveau canal : tout id apparaissant dans un `posologie_detail[].sources` existe
dans `sources.references_primaires` **ou** dans `sources.reco_officielle.references` du même nœud.

### Décision clé

**C'est cette session qui rend le canal sûr.** La carte ignore un id inconnu en silence, par politique
assumée (`OptionCard.tsx`) — sans cet invariant, une source pointant vers un id inexistant
**disparaîtrait de l'écran sans rien casser**. C'est la pire des sorties pour un fait de sourçage :
invisible au praticien, invisible au banc.

### Lire / Modifier

Modifier : `src/features/decision/engine/banc/invariants-contenu.test.ts` uniquement.

### Étapes

1. Lire I8b et **calquer sa structure** (même façon de parcourir les nœuds, même forme de message
   d'échec nommant nœud + option + id fautif).
2. Étendre la collecte des ids valides au second registre (`reco_officielle.references[].id`), en
   ignorant les entrées sans `id` — elles sont légitimement non citables.
3. Écrire l'assertion. Elle passe au vert **immédiatement** : aucun contenu n'utilise encore
   `sources[]`. C'est voulu — l'invariant est écrit AVANT le contenu qu'il garde (convention maison,
   cf. P14 : « on ne corrige jamais un défaut puis on le vérifie avec un outil écrit après coup »).
4. Vérifier que l'invariant n'est pas vide : introduire temporairement un `sources: ['id-bidon']` dans
   une fixture ou un nœud, constater le rouge, **puis annuler**. Consigner le message obtenu dans le
   rapport de session.
