# S6 · T‑025 — Validation référent → `valide` + D18 + re‑pointage P2·S3–S7

**Modèle/effort** : humain (référent) + assistance Opus pour la mise en forme. **Dépend de** : S5.
**Sortie** : YAML `statut: valide`, `DECISIONS.md` D18, sessions P2·S3–S7 re‑pointées, STATUS/TASKS.
**Gate humaine bloquante.**

## But

Clore la fusion : signature clinique, gouvernance, et préparation de la reprise de P2.

## Étapes

1. **Revue clinique référent** du nœud fusionné : parcourir le rapport S4 (findings MOYENNE/BASSE à arbitrer),
   la table des portes, le gating de terrain et les seuils. Corriger le contenu si besoin (retour S3→S4 pour
   toute modif de valeur clinique — ne pas court‑circuiter la re‑vérification).
2. **Promotion** : `meta.statut: valide`, `version: 1.0`, **changelog** daté (résumé : fusion B+C+D + gating
   terrain + portes + priorité conditionnelle + flag < 6,5 % + primer position). Auteur « référent DT2 ».
3. **D18 dans `DECISIONS.md`** : « Fusion des nœuds de prescription orale B+C+D en un nœud `prescription`
   unique piloté par `traitements_en_cours` + `position_vs_cible` ; motivation (modèle mental clinicien,
   suppression des coutures, gating négatif écrit une seule fois) ; conséquences (B/C/D retirés ; E/A/F/H
   inchangés) ; renvoi au plan P3 ». Noter que D12/D13/D14/D15/D16 restent la base d'encodage (inchangés).
4. **Re‑pointage P2·S3–S7** (cf. `index.md` §Rapport à P2) :
   - [`../P2/S4.md`](../P2/S4.md) : retirer les vignettes « traversée B→C→D » ; **ajouter** vignettes
     patient‑fragile / IMC‑bas / infections uro / sous‑cible / intolérance (attaquer le neuf).
   - [`../P2/S3.md`](../P2/S3.md) et [`../P2/S5.md`](../P2/S5.md) : cibler en priorité les **règles nouvelles**
     (non‑EBM historique) ; mettre à jour la topologie (7 nœuds → prescription + A/E/F/H).
   - [`../P2/index.md`](../P2/index.md) : note « S3–S7 s'exécutent sur le module fusionné (post‑P3) ».
5. **Fin de tâche** (skill `/fin-de-tache`) : STATUS.md, TASKS.md (T‑020→T‑025 done, T‑026 Track B état),
   commit tâche par tâche, un seul push.

## Critère de sortie

Nœud `prescription` **`valide`** ; D18 écrit ; P2·S3–S7 re‑pointés et **prêts à lancer**. → l'utilisateur
peut engager le budget Opus S3–S7 sur la vraie cible.
